Circuit Condensation

Preprint on arXiv · 2608.27254

Post-training can make a behavior's circuit small enough to check by hand.

A circuit is the set of internal connections a model uses for one behavior. Searching a frozen model for one often returns hundreds of connections, too many to inspect. Circuit Condensation fine-tunes the model while it prunes, so the same behavior runs through a circuit you can test edge by edge.

Method

One round of condensation

Rounds repeat until the next cut would break the behavior or the model's general ability.

  1. 1Rank

    Score every connection by how much the behavior depends on it, using integrated-gradient attribution (EAP-IG).

  2. 2Cut

    Remove the lowest-scoring connections: 30% per round at first, fewer as the circuit gets small.

  3. 3Heal

    Train a small LoRA adapter so the model matches its original outputs using only what is left.

  4. 4Check

    Keep the cut only if task accuracy and perplexity on general text stay within tolerance. Otherwise retry a smaller cut.
